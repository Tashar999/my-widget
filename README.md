# my-widget

Starter for the CS Club widget hackathon. Three files, plain HTML, CSS and JavaScript.

- `index.html` is what's on the page
- `style.css` is how it looks
- `script.js` is what it does

Build your widget in those three files. There are two finished examples to look at:

- `standard/` is a clock with a greeting. Small enough to read in five minutes.
- `advanced/` is a weather widget. It calls a real API and retries when the request fails.

To see one, right-click its `index.html` → **Open with Five Server** (step 4 below).

## Getting started

1. One of you clicks **Fork** (top right), then **Create fork**. Now you have your own copy.
2. Working with a partner? On your fork, go to **Settings → Collaborators → Add people**. They accept the invite.
3. Each of you: click the green **Code** button → **Codespaces** → **Create codespace on main**.
4. In the Codespace, open the **Extensions** tab, search **Five Server** and install it. Then right-click `index.html` → **Open with Five Server**. It reloads by itself every time you save.
5. To save your work: **Source Control** tab → type a message → **Commit** → **Sync Changes**.

## Working with a partner

Split the files so you don't edit the same lines: one of you takes `index.html` and `script.js`, the other takes `style.css`. Swap halfway. Commit small and hit **Sync Changes** often so you get each other's work. If you get a merge conflict, don't panic: ask for help or ask the AI to explain it.

## Using AI

Open `ai.md`, copy all of it, and paste it as the first message in a new Gemini chat. Then tell it which tier you want. It sets how much the AI does for you and how much you figure out yourself.

If you just want the AI to build everything, skip `ai.md`. You're still responsible for every line you commit.
